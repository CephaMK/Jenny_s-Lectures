# Demo Script

1. Open the app. Show the title and empty input state.
2. Select "Word" input type, type `Ninampenda`, click **Analyze**.
3. Point out the morphology breakdown (subject, tense, object, root).
4. Point out the grammar checks (agreement, verb structure).
5. Read the plain-language explanation aloud.
6. Try `Anasoma` to show a second, different example.
7. Use the "Ask the Language Engine" box with a sample question to preview
   where the RAG/chatbot feature will eventually live.
